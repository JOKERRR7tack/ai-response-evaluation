# Evaluation Rubric
Each response is scored 1–5 for Accuracy, Relevance, Completeness, Clarity, and Instruction Following.
1 = poor/fundamentally deficient, 3 = mixed/partly satisfactory, 5 = strong.
Factual Error is Yes/No for materially false factual claims. Error Type separately captures reasoning and instruction-following failures.
Confidence is 1–5. Overall Score is the mean of the five quality dimensions.
This is a small portfolio dataset, not a statistical benchmark.
