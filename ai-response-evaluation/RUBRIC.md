# AI Response Evaluation Rubric

Score each dimension from 1 to 5.

- 1 = Very poor
- 2 = Poor
- 3 = Acceptable
- 4 = Good
- 5 = Excellent

Dimensions:
- Accuracy: Is the answer factually/logically correct?
- Relevance: Does it directly address the prompt?
- Completeness: Does it provide enough information to satisfy the request?
- Clarity: Is it easy to understand and well organized?
- Instruction Following: Did it follow the requested format, scope, and constraints?
- Factual Error: Mark Yes if a substantive factual error or unsupported claim is present.

This starter dataset contains intentionally high-quality example responses to demonstrate the methodology. Future evaluations should include a realistic mix of quality levels and should be scored by the project owner using the rubric.
